# 🚀 ReactMaster Studio 2.0 - Guia Prático dos 11 Conceitos de React

Aplicação React desenvolvida para demonstrar, ensinar e aplicar na prática **todos os 11 conceitos fundamentais do React** com interfaces interativas, componentes reutilizáveis e mini-aplicações reais.

---

## 📌 Os 11 Conceitos Implementados

1. **JSX**: Sintaxe semelhantes a HTML em JS com interpolação de expressões `{ }`.
2. **Componentes**: Divisão modular e reutilizável da interface.
3. **Props**: Envio de dados, callbacks e a propriedade especial `children`.
4. **Virtual DOM**: Reconciliação do React Fiber e simulador de *diffing* em tempo real.
5. **Listas e keys**: Iteração com `.map()` e `key`s únicas e estáveis.
6. **Renderização condicional**: Operadores ternários, curto-circuito `&&` e telas dinâmicas.
7. **State e useState**: Estado reativo, contadores e gerenciamento de estados complexos.
8. **Formulários**: Componentes controlados com validação síncrona.
9. **useEffect**: Efeitos colaterais, sincronização externa e funções de limpeza (*cleanup*).
10. **Consumo de APIs**: Consumo da API REST do GitHub com tratamento de *loading* e *error*.
11. **React Router**: Roteamento SPA com `BrowserRouter`, `Routes`, `Route` e `useParams`.

---

## 🛠️ Tecnologias Utilizadas

- **React 18**
- **Vite**
- **React Router DOM v6**
- **Tailwind CSS**
- **Lucide React** (Ícones)

## 🚀 Como Executar

```bash
# 1. Instalar as dependências
npm install

# 2. Executar o servidor de desenvolvimento
npm run dev
```

Acesse `http://localhost:5173` no seu navegador.
